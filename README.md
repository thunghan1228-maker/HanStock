# HanStock 台灣股票選股系統

HanStock 是一套台灣股票行情、族群比較與策略選股系統。

## 目前已完成

- 永豐 Shioaji API 登入
- 股票行情快照
- 一分鐘 K 線
- 五分鐘 K 線合成
- Git 與 GitHub 私人備份

## 未來功能

- 即時行情訂閱
- 日 K 與五分鐘 K 資料庫
- Rule1 日線策略
- Rule2 五分鐘 K 策略
- 多方與空方選股
- 股票族群排行
- HanStock 網站串接
- LINE Bot 串接
- 手機 App

## 安全提醒

API Key 與 Secret Key 儲存在本機 `.env`，不得上傳至 GitHub。
