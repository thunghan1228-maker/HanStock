# Rule1 日線多方策略規格

## 策略類型
日線策略（非5分鐘策略）

## 觸發條件（四項全部成立）

| 條件 | 名稱 | 判斷邏輯 |
|------|------|---------|
| 1 | 5日均線向上 | 今天 MA5 > 昨天 MA5 |
| 2 | 前一交易日收盤為近10日收盤新高 | 昨天收盤 ≥ 近10日最高收盤價 |
| 3 | 現價／今日收盤高於5日均線 | 今天收盤 > 今天 MA5 |
| 4 | 現價／今日收盤低於前一交易日收盤 | 今天收盤 < 昨天收盤 |

## 資料需求
- 至少 11 個交易日的日線收盤價
- 近10日窗口以「昨天為最後一天」計算

## 排除條件
- 處置股
- 權證

## 實作位置
- 後端：`HanStock/rule1.py` → `evaluate_rule1()`
- 前端：`taiwan-stock-groups/client/src/pages/Rule1Scan.tsx`
