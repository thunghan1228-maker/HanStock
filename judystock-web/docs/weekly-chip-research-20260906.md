# 每週籌碼研究更新

基礎：使用者提供的 HanStock 第660版（2026/09/06）。app、lib、db、worker、scripts、tests、build 與套件設定已逐檔忽略換行格式核對，與取得的網站原始碼一致。

## 使用方式

1. 首頁下方選「每週籌碼分析」。新增「本週變化與持續性」研究區，原有上週績效、本週20大、三項主力分數及族群排行保留。
2. 選研究週次、回看4／6／12週、正分前10／20名、顯示10／15／20／30檔。
3. 點摘要篩選新進榜、掉出榜、負轉正或正轉負；也可篩選連三週升分、六週內五週升分。
4. 點族群縮小個股範圍，或輸入代號／名稱搜尋。
5. 累積榜列出有效資料週數、上榜次數、近四週上榜、全部有效週平均及正／負分合計。下方呈現名單前6檔的九週軌跡。
6. 「帶入選股」將目前顯示的股票（最多30檔）、研究週次與條件標籤帶到綜合選股。可再套用既有條件；移除每週限制或清除條件可回到全市場。

## 計算口徑

- 延續 HanStock 法人週分數，單位是分。沒有複製參考站的數據、密碼或計分公式。
- 升分＝本週法人週分數減上週；不是集保持股百分比，也不是股價報酬率。連三週升分需要4週分數，六週內五週升分需要7週。
- 以固定相隔7日的週格追蹤；沒有對應週次、股票、有限數值或相同權重時視為缺值。假日或特殊結算造成日期不連續時採保守的資料不足，不猜測連續性。
- 新進與掉出依使用者選擇的正分前10／20名，並要求相鄰兩週都有資料。負轉正和正轉負不包含0分。
- 正／負週都計入平均，兩者合計分開顯示。沒有的週不補0；有效週數和回看窗口分開標示。
- 族群採歷史存檔的主族群；同步率為升分家數／相鄰兩週有效家數，分母不包括缺值，不聲稱涵蓋全市場。
- 歷史研究只讀所選週以前的存檔；沒有12週就呈現實際可用週次。舊存檔若未記錄權重，不納入跨週比較。
- 「帶入選股」是該週名單與最新行情條件取交集，不是歷史回測。行情及籌碼資料日期保留在選股頁。
